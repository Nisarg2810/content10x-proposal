# Content 10x proposal

A single page proposal site covering three ways to fix the blog and website: a blog restructure inside the current site, an AI assisted new site, and a custom site with its own CMS.

Static HTML, CSS and vanilla JS. Every page is generated by `build.py`, so copy lives in one place.

    python3 build.py

All product screens are drawn in HTML and CSS and animate on their own, so the proposal shows what each option looks like without any stock imagery.
